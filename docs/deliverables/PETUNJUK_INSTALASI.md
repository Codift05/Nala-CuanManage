# Petunjuk Instalasi NALA

## Persyaratan

- Perangkat Android yang kompatibel dengan versi minimum pada build NALA.
- Koneksi internet aktif.
- Ruang penyimpanan kosong minimal 150 MB.

## Instalasi APK

1. Unduh atau salin `NALA-v1.0.0-release.apk` ke perangkat Android.
2. Buka berkas APK dari aplikasi pengelola berkas.
3. Jika diminta, izinkan instalasi aplikasi dari sumber tersebut.
4. Pilih **Instal**, tunggu hingga selesai, lalu buka **Nala**.
5. Masuk menggunakan akun demo yang tercantum pada berkas `AKUN_DEMO.txt`.

## Alur verifikasi singkat

1. Masuk ke aplikasi.
2. Periksa ringkasan pada Beranda.
3. Tambahkan satu transaksi.
4. Buka Budget dan Laporan.
5. Periksa Financial Habit Score.
6. Buka Nala Coach dan kirim pertanyaan finansial non-sensitif.

## Pemecahan masalah

- Pastikan perangkat terhubung ke internet jika login gagal.
- Pastikan tanggal dan waktu perangkat disetel otomatis.
- Hapus versi NALA lama apabila Android menolak APK karena signature berbeda.
- Hubungi tim melalui kontak resmi yang dicantumkan pada dokumen teknis jika layanan demonstrasi tidak tersedia.
